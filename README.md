# HFT Leet Solutions & Algorithmic Practice
Daily training ground for algorithms and data structures, specifically focused on runtime and space complexity requirements for HFT interviews.

## Structure
* **01_graphs/**: Solutions to Graph problems (Medium/Hard) using optimized standard libraries.
* **02_dynamic_programming/**: Implementations tracking complex state machines and DP matrix optimizations.

## Target Complexity
* Time Complexity: O(1), O(log n), or O(n) benchmarks.
* Language: Modern C++ and Python for rapid prototyping.
